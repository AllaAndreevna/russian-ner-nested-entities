Метод: дообучение предобученного компактного русскоязычного трансформера cointegrated/rubert-tiny2 (3 слоя, hidden 312; публичная модель Hugging Face) для разметки последовательностей, с несколькими выходами для вложенных сущностей.

Предобработка: разбиение на предложения и токенизация razdel; слова подаются в WordPiece-токенизатор исходной модели (tokenizers, файл bert_tokenizer.json), метка и предсказание берутся на первом подтокене слова. Длинные предложения режутся на куски по 80 слов (и меньше, если не влезают в 512 позиций).

Уменьшение размера: словарь модели (83828 токенов) обрезается до специальных токенов, всех коротких кусков (до 2 символов, кириллица/латиница/символы) и самых частых токенов обучающих текстов (train или train+dev); остальные токены при предсказании превращаются в [UNK]. Позиционные эмбеддинги обрезаны до 512. Веса хранятся в fp16 (bert_model.pt).

Вложенные сущности: сущности (только непрерывные; тексты с разрывными исключены) сортируются по длине и жадно раскладываются по 3 слоям так, чтобы внутри слоя спаны не пересекались (внешние, вложенные, вложенные во вложенные). Модель имеет общий энкодер и по одной линейной голове (BIO-тип) на слой; лосс - сумма кросс-энтропий по слоям. Предсказания слоёв переводятся в спаны [start, end) по символьным смещениям и объединяются.

Обучение: AdamW (lr энкодера 1e-4, голов 1e-3), линейный warmup/decay, батч 32. Число эпох выбрано по macro-F1 на dev (обучение на train); финальная модель обучена на train+dev с тем же числом эпох. Test для обучения и подбора не использовался.
