Метод: дообучение предобученного компактного русскоязычного трансформера cointegrated/rubert-tiny2 (3 слоя, hidden 312; публичная модель Hugging Face) для разметки последовательностей, с несколькими выходами для вложенных сущностей.

Предобработка: разбиение на предложения и токенизация razdel; слова подаются в WordPiece-токенизатор исходной модели (библиотека tokenizers, файл bert_tokenizer.json; токенизатор различает регистр), метка и предсказание берутся на первом подтокене слова. Длинные предложения режутся на куски по 80 слов (и меньше, если не влезают в 512 позиций).

Уменьшение размера (лимит архива 16 МБ). Основной вес модели - матрица эмбеддингов словаря (83828 токенов x 312). Используется весь словарь без символов других алфавитов (остаются кириллица, латиница, цифры и знаки; остальные токены при предсказании превращаются в [UNK]), а матрица эмбеддингов хранится в низкоранговом виде: E ~ A x B, где A (токены x r) и B (r x 312) инициализируются усечённым SVD предобученной матрицы, обучаются вместе с моделью, а A сохраняется в int8 с масштабом по строкам. Ранг r подобран на dev; позиционные эмбеддинги обрезаны до 512; остальные веса хранятся в fp16. Точные значения параметров итогового запуска записаны в bert_meta.json (ключи emb_rank, train_args).

Эмбеддинг регистра: к эмбеддингу каждого токена добавляется обучаемый эмбеддинг класса слова (строчное / с заглавной / ЗАГЛАВНЫЕ / с цифрой / знак / смешанный). Он возвращает информацию о заглавной букве, которая теряется у токенов [UNK].

Вложенные сущности: сущности (только непрерывные; тексты с разрывными сущностями исключены) сортируются по длине и жадно раскладываются по 3 слоям так, чтобы внутри слоя спаны не пересекались (внешние, вложенные, вложенные во вложенные). Модель имеет общий энкодер и по одной линейной голове (BIO-тип) на слой; лосс - сумма кросс-энтропий по слоям. Предсказания слоёв переводятся в спаны [start, end) по символьным смещениям и объединяются.

Обучение: AdamW (weight decay 0.01), линейный warmup/decay, градиентный клиппинг 1.0, dropout 0.1 в головах. Число эпох выбрано по macro-F1 на dev (обучение на train); финальная модель обучена на train+dev с тем же числом эпох. Test для обучения и подбора не использовался. Модель обучалась на GPU (Google Colab), инференс - на CPU с ограничением потоков torch.set_num_threads.
