Метод: разметка последовательностей (BIO) линейными цепями CRF (sklearn-crfsuite, L-BFGS, L1+L2-регуляризация). Для вложенных сущностей используется несколько CRF-моделей ("слоёв").

Предобработка: разбиение на предложения и токенизация razdel; смещения токенов пересчитываются в координаты исходного текста.

Разметка для обучения: из аннотаций T корпуса NEREL v1.1 (train; в финале train+dev) берутся непрерывные сущности, тексты с разрывными сущностями пропускаются. Сущности сортируются по длине (сначала длинные) и жадно раскладываются по трём слоям так, чтобы внутри слоя спаны не пересекались: слой 0 - внешние сущности, слой 1 - вложенные в них, слой 2 - вложенные во вложенные. На каждый слой обучается отдельный CRF с общим набором признаков и метками BIO-тип.

Признаки токена: слово в нижнем регистре, стем (русский Snowball-стеммер из nltk, работает без внешних данных), префиксы 2-3 и суффиксы 1-4 символа, форма слова (Xxxx/dd), регистр, цифры, длина, позиция в предложении, биграммы с соседним словом; для соседей в окне +-2: слово, стем, суффикс 3, форма, регистр.

Предсказание: каждый слой размечает предложение независимо, BIO-теги переводятся в спаны [start, end) по символьным смещениям токенов, результаты слоёв объединяются. Декодирование: Витерби либо, если задан порог O_MIN, выбор тега по маргинальным вероятностям (токен получает O, только если P(O) >= O_MIN) - это повышает recall.

Ограничение размера: L1-регуляризация и отсечение редких признаков (min_freq).
Гиперпараметры (c1, c2, min_freq, O_MIN) подбирались только на dev; test для обучения и подбора не использовался.
